# Menu Guard

AI-assisted menu translator that flags **possible** allergens and
halal-risk ingredients, and tells the user when it is NOT sure.

## Status
Prototype v0.1 (keyword-based). Work in progress.

## How to run
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    streamlit run app.py

## Disclaimer
This tool gives hints only. It is not medical or religious advice.
Always confirm with restaurant staff.
